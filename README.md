# MudraVision – Computer Vision Based Mudra Recognition

## About the Project

MudraVision is a Computer Vision-based project that identifies different mudras (hand gestures) and provides corresponding audio information through MP3 files.

The system recognizes hand gestures and plays an audio explanation of the identified mudra, making traditional mudra knowledge more accessible through technology.

## Features

- Real-time hand gesture recognition.
- Identification of different mudras.
- Automatic MP3 audio playback.
- Audio-based explanation of recognized mudras.
- Computer Vision-based gesture analysis.

## Technologies Used

- Python
- Computer Vision
- Image Processing
- Machine Learning / Deep Learning
- MP3 Audio Processing

## Project Structure

- `src/` – Source code
- `models/` – Trained models
- `audio/` – MP3 audio explanations
- `images/` – Project screenshots

## How It Works

1. The camera captures the user's hand gesture.
2. The system analyzes the hand gesture.
3. The corresponding mudra is identified.
4. The associated MP3 audio explanation is played.

## Applications

- Digital learning of traditional mudras.
- Gesture recognition systems.
- Interactive educational applications.
- Preservation of traditional knowledge through technology.
